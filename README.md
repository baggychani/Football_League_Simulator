# Premier League infinite season simulator

An intentionally visual Premier League-style simulator. Pick a club and the app simulates complete 380-match seasons until that club becomes champion. Every scoreline is generated by the same independent-Poisson match model; champions are never sampled directly.

## Run

```bash
npm install
npm run dev
npm run test
npm run build
```

The local launcher uses port `27183` by default:

```bash
python start.py
python start.py --port 28191
```

## Static market calibration

Polymarket prices have one precise meaning in this project: they calibrate the **pre-season static base-strength vector**. Calibration deliberately disables form, momentum, medium-term state, and season-to-season evolution.

The production infinite-season simulator starts from those calibrated base ratings and then enables the dynamic model. Its observed championship probabilities may therefore differ from Polymarket. That difference is intentional and is not treated as calibration failure.

Open the browser Calibration Lab with:

```bash
python calibrate.py
```

For headless calibration:

```bash
npm run calibrate -- \
  --market ./src/data/default-market.json \
  --start-mode hybrid \
  --coarse-seasons 10000 \
  --jacobian-seasons 10000 \
  --seasons 30000 \
  --iterations 6 \
  --head-seasons 100000 \
  --final-seasons 200000 \
  --final-max-seasons 300000 \
  --seed 12345 \
  --output ./src/data/calibrated-ratings.json
```

`cold`, `warm`, and `hybrid` start modes are supported. Hybrid evaluates both log-market scale candidates and the existing output ratings, then starts from the better unified objective.

A small structural end-to-end check is available as `npm run calibrate:smoke`. It verifies plumbing, not statistical convergence.

### Objective and completion

Each team uses a target-specific tolerance:

```text
target >= 20%       tolerance = 0.30pp
target >= 5%        tolerance = 0.50pp
target >= 1%        tolerance = max(12% of target, 0.10pp)
target < 1%         tolerance = max(25% of target, 0.025pp)
z_i                 = (simulated_i - target_i) / tolerance_i
```

The single objective used by scale selection, LM refinement, reporting, best-state selection, and final validation is:

```text
mean Huber(z_i)
+ Arsenal/Manchester City combined-mass loss
+ Arsenal/Manchester City log-split loss
```

Final validation uses an independent seed bank. It starts at 200,000 seasons and adds 50,000-season batches up to 300,000 when a 95% Monte Carlo interval still overlaps a tolerance boundary. The output stores, for every club, the simulated mean, residual, tolerance, standard error, and 95% interval.

### Optimizer

- All candidate comparisons use counter-based common random numbers addressed by `(seed, season, fixture, side)`.
- Poisson scores are sampled through a one-uniform inverse CDF, so a lambda change cannot shift later random draws.
- Ratings use a centered 19-dimensional zero-sum basis.
- Central finite differences estimate the full championship-probability Jacobian.
- Levenberg–Marquardt steps use damping and a rating-space trust region.
- The Jacobian is periodically recomputed and otherwise updated with Broyden's formula.
- A final two-dimensional solver separately adjusts Arsenal/Manchester City common strength and contrast.
- The optimizer returns the best independently validated candidate, not merely its last proposal.
- Market ordering uses proper PAVA with explicit equal-probability tiers. The former arbitrary adjacent-gap cap is gone.

## Score model

For each fixture:

```text
rawDiff       = ratingEffect * (ratingHome - ratingAway + form contribution)
effectiveDiff = maxDiff * tanh(rawDiff / maxDiff)
lambdaHome    = exp(log(baseGoalRate) + homeAdvantage + effectiveDiff)
lambdaAway    = exp(log(baseGoalRate) - homeAdvantage - effectiveDiff)
```

`ratingEffect` is fixed and the rating vector carries the calibrated scale, avoiding an unidentifiable product of two free scale parameters. Smooth `tanh` compression replaces the old hard `±2.45` clamp. Calibration output includes raw/effective difference and expected-goal distribution diagnostics, plus the near-cap fixture ratio.

Champion prices alone cannot identify separate attack, defence, draw tendency, base goals, and home advantage. The project therefore fixes the score model (`baseGoalRate: 1.34`, `homeAdvantage: 0.14`) and calibrates relative latent ratings inside it. Ratings are not claims about real teams' absolute quality.

## Dynamic production model

Production matches use effective strength `R = B + C + F`: calibrated base strength `B`, medium-term state `C`, and short-term form `F`. Unexpected results produce larger shocks than expected results, and season-end consistency gates long-run changes. Structural club tiers affect persistence and recovery, never the initial static calibration target.

## Calibration output contract

`src/data/calibrated-ratings.json` schema v2 contains:

- the market snapshot and normalized targets;
- best static ratings and independent validation probabilities;
- per-team residual, tolerance, normalized residual, SE, and 95% interval;
- Arsenal/Manchester City combined-mass and conditional-split diagnostics;
- score-model distribution and saturation diagnostics;
- optimizer/Jacobian diagnostics and sensitivity estimates;
- training/validation fidelity and seed-bank configuration;
- `calibrationMode: "static-baseline"` and the intentional static/dynamic contract.

The browser and Node CLI call the same calibration engine. Browser workers only provide a parallel evaluator; they do not maintain a second optimizer implementation.
